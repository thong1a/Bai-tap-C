# Bài tập 1: Ứng dụng dòng lệnh đơn giản

Cấu trúc tối giản với một tệp mã nguồn và `Makefile`. Chương trình đọc các số nguyên từ đối số dòng lệnh, bỏ qua giá trị không hợp lệ và in tổng, số lượng và trung bình.

## Cách build & chạy
```bash
make
./cli-summary 1 2 3 4
```

## Mục tiêu học
- Cấu trúc dự án nhỏ nhất.
- Biên dịch trực tiếp một tệp C thành chương trình.
- Sử dụng `make` với quy tắc tối giản.

# Exercise 1: Simple command-line app

A minimal layout with a single source file. The program reads integer arguments, skips invalid entries, and prints the count, sum, and average.

## Build & run
Write your own Makefile or direct compile command. A reference workflow is in `SOLUTION.txt` if you want to compare with your approach.

## Learning goals
- Understand the smallest possible project layout.
- Compile a single C file into an executable.
- Practice authoring a basic build recipe yourself.
